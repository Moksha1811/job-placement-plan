## CERTIFICATION ROADMAP

### Option 1: Docker Associate Certification (DCA)

**Eligibility**: Completed Docker course + hands-on practice

**Cost**: ₹30,000-35,000 (exam fee)

**Duration**: 2 months preparation

**Content**:
- Docker architecture and concepts
- Building images
- Running containers
- Networking and volumes
- Security
- Docker orchestration

**How to Prepare**:
1. YouTube (TechWorld with Nana)
2. Kodekloud Docker labs (essential)
3. Official Docker documentation
4. Mock exams on Udemy

**Target Timeline**: Week 5-6 (after Portfolio Project 1)

**Resources**:
- Kodekloud Docker labs
- Docker official docs: docs.docker.com
- Udemy "Docker Associate Exam" prep course (₹500-800)
- Pramp for mock interviews

**ROI**: High for freshers — shows practical expertise, not just theory

- Security and compliance
- AWS Well-Architected Framework

**How to Prepare**:
1. AWS Skill Builder (free tier) — AWS Fundamentals

**Target Timeline**: Week 8-10

**Resources**:

**ROI**: Very high for India — most sought-after fresher certification
